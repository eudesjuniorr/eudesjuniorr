### 🚀 About me

I'm **self-taught** and study electronics, Arduino, and industrial automation on my own — learning by doing, testing, failing, and documenting the process. This profile (and my [Lab](https://site-pessoal-umber.vercel.app/)) works as a personal archive of projects: each one with motivation, theoretical background, calculations, schematics, and commented code — both for my own future reference and for anyone who wants to learn along the way.

I'm currently taking my first steps in:

- 🔌 **Arduino and microcontrollers** (AVR, ESP32, STM32)
- 🏭 **Industrial automation** (PLCs, industrial protocols)
- ⚡ **Electronics** — from basic circuits to power electronics

### 🎯 Areas of interest

- Arduino and microcontrollers (AVR, ESP32, STM32)
- Sensors and instrumentation
- PID control and control systems
- Industrial automation (PLCs, industrial protocols)
- IoT and wireless communication (MQTT, LoRa, Wi-Fi)
- Power electronics and drives

### 🛠️ How I document my projects

Every published project follows a format inspired by scientific papers:

1. Motivation
2. Theoretical background, formulas, and relevant calculations
3. Component list
4. Schematics
5. Commented source code
